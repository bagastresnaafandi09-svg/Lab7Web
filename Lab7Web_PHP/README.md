## Cara Menjalankan
1. Jalankan XAMPP.
2. Klik **Start** pada Apache.
3. Salin folder `Lab7Web_PHP` ke direktori `C:\xampp\htdocs`.
4. Buka browser.
5. Akses `http://localhost/Lab7Web_PHP/`.
6. Pilih latihan dari halaman menu.

## Ringkasan Latihan
1. `latihan1.php`: menjalankan PHP dan menampilkan waktu server.
2. `latihan2.php`: variabel, operator, perhitungan nilai, dan percabangan.
3. `latihan3.php`: array dan perulangan foreach.
4. `latihan4.php`: function untuk diskon dan luas persegi panjang.
5. `latihan5.php`: menerima input menggunakan metode GET.
6. `latihan6.php`: menerima input menggunakan metode POST.
7. `latihan7.php`: menghitung subtotal transaksi barang.
8. `mini_project.php`: formulir data mahasiswa dengan validasi server-side.

## Pengujian
- Input valid: isi seluruh kolom dengan data yang sesuai, misalnya semester 2 dan email `bagas@example.com`.
- Input tidak valid: kosongkan kolom wajib, masukkan NIM dengan huruf, gunakan email tanpa format yang benar, atau masukkan semester di luar rentang 1-14.

## Kesimpulan
Praktikum ini memperkenalkan pemrograman server-side menggunakan PHP, mulai dari sintaks dasar hingga pemrosesan dan validasi data dari formulir.
